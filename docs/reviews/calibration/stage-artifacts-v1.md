以下为评分用的合成材料。人名、批准号、执行输出均为题面事实，不作为 Restart 教学案例的实际批准或测试记录。复核人逐份独立打分。

## D1 · S00 设计文档

输入 R1：值班人员在单个 Deployment 详情中确认目标后模拟重启。用户要知道请求是否已提交，排除批量与实际集群。本地案例范围由样本负责人在记录 U1 选定。

设计文档 rev D1：值班人目前需要在多个窗口核对目标与结果。选定已有详情页，显示 namespace/deployment 与操作 ID；保留一个确认按钮。对比命令摘要，选择页面以验证点击取消和提交后的反馈。只做单目标本地模拟，下一步由原型作者按 U1 制作。成功标准留作“改善体验”；未定义如何通过体验判断改善。

## D2 · S00 风险摘要

摘要 rev D2 全文：“系统存在风险，下一步完善。”

输入 P3：教学授权人已批准 build R3 在本地 Mock 执行用例 C1，取消后请求计数须为零。原始回执 E3：相同 build、环境和用例，点击取消后 POST 计数为 1，断言失败，exit 1。
