### 如何复验边界

- **未到达**：输入“项目仅到 S05，复查 S13”。核对输出为未到达，不累加为 0 分。
- **缺整套材料**：输入“S13 已到达，交付清单为空，计划、批准范围、执行记录和报告均未交”。报告应列出四类缺件，不构造逐项分。
- **已交但无法读取**：在 Windows 用 `File.Open(path, Open, Read, FileShare.None)` 临时独占 D4 副本，再让另一个进程读取。本次实际触发了 Python 的 `PermissionError`。给评审者的材料是提交清单及该读取结果。解除独占并取得可读副本后，可发起另一次复查。
- **同版同材料**：保持 D3/P3/E3、规则 1.0 及范围不变，附 R-D3，再明确发起复评。五项分别沿用 R-D3 中的证据及唯一修改建议。
- **规则改版**：复制规则 1.0，仅在 S13 A 的 2 分条款增加“已执行用例还需注明浏览器及版本”，并在 1 分条款纳入缺少该信息的情形，标记为 `test-1.1`。附 R-D4，在完全相同的 D4/P3/E3 上评分。应同时保留原基线与新基线的规则版本、各项分数及变化原因。
