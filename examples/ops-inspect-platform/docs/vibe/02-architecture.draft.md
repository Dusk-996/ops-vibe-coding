# 选型草案（DRAFT）：ops-inspect-demo

- **阶段**：DRAFT（已交 `$grilling` 确认 Q1–Q4）
- **上游基准**：`docs/vibe/01-design.md`、`docs/vibe/01-prototype/index.html`

## 从原型与需求提取的核心能力信号
1. **静态资产登记**：主机名、连接地址/IP、服务器种类、厂商、采集驱动类型（`local` / `ssh` / `mock`）、SSH 连接参数引用；支持 CSV/JSON 导入预检与导出。
2. **主动巡检检测（非手工台账）**：支持手动点击“立即巡检”与定时巡检，由采集引擎主动检测各目标服务器的**总内存、剩余内存、CPU 核数、CPU 使用率**，记录最后检测时间与检测状态（正常/关注/高负载/检测失败）。
3. **每日定时邮件推送**：持久化每日推送时间 `HH:MM` 与收件邮箱，按 Markdown 汇总推送，支持手动立即推送（`409` 防并发锁、`504` 超时不重试）、真实 SMTP（环境变量注入）与本地模拟收件箱双模式。
4. **认证授权与全量审计**：`admin`（读写/导入/巡检/改定时/推送）与 `viewer`（只读/导出）；未登录写操作 `401`，`viewer` 写操作 `403`。
