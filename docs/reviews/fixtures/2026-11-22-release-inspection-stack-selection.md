## 系统组件组成

Python 在本机同步读取并校验一份快照，交给展示层可直接使用的数据与状态。演练只需要一个数据处理进程，无独立 Backend、Worker、Scheduler、Agent、Kubernetes Controller 或 Operator。页面布局和接入方式由原型及后续规格确认。

## 最小架构方案

## 数据与任务执行方案

无时序数据写入、持久任务、调度或推送。解析失败显示文件名、失败类型，修正输入后可手动重新读取；无自动重试。重复读取同一文件没有外部副作用。

## 安全与运行基线

读取权限仅限提供的本地文件。配置只接收路径；错误输出包含文件名与错误类别，保留原始文件，不把完整输入写入日志。短时进程正常结束或中止时不写结果，只读查询无重放或部分提交风险。无常驻健康检查、外部请求超时、数据库迁移备份、操作审计、并发任务、恢复队列、远程命令或 SSH/Kubernetes 凭证。结果与诊断只在本次调用显示，程序不建立长期日志归档。
